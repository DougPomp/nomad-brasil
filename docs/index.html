🚀 Como Rodar o NOMAD Brasil no seu Computador

O NOMAD Brasil foi feito para funcionar 100% desconectado da internet através do Docker no seu HD externo ou notebook.

No Windows (Instalador Automático de 1 Clique):

  1. Baixe o repositório ou clone via terminal:
    2. git clone https://github.com/DougPomp/nomad-brasil.git
    cd nomad-brasil
  2. Dê dois cliques no instalador: setup-nomad-brasil.bat
  3. O instalador baixa o mapa vetorial nacional (1,57 GB), a Wikipédia e inicia tudo sozinho em:
    4. 🌐 Portal Tático: http://localhost:8000 | 📚 Kiwix Wikipédia: http://localhost:8090

No Linux / macOS / Raspberry Pi:

chmod +x setup-nomad-brasil.sh
./setup-nomad-brasil.sh
