🚀 Como Rodar o NOMAD Brasil no seu Computador

O NOMAD Brasil foi feito para funcionar 100% desconectado da internet através do Docker.

No Windows (Instalador Automático de 1 Clique):

  1. Baixe o projeto pelo botão "Baixar Projeto" ou clone via terminal:
    2. git clone https://github.com/DougPomp/nomad-brasil.git
    cd nomad-brasil
  2. Dê dois cliques no arquivo: setup-nomad-brasil.bat
  3. O instalador baixa o mapa do Brasil (1,57 GB), a Wikipédia e sobe o sistema automaticamente em:
    4. 🌐 Portal: http://localhost:8000 | 📚 Kiwix Wikipédia: http://localhost:8090

No Linux / macOS / Raspberry Pi:

chmod +x setup-nomad-brasil.sh
./setup-nomad-brasil.sh
